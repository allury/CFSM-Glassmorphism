## 本地无头浏览器回归

用本机 Chrome 的无头模式通过 CDP 驱动本地 mock，逐个场景检查：
- 可见文字中不得出现 `—`、`NaN`、`undefined`、`null`、`Infinity`、`Invalid Date`、`[object Object]`；
- 控制台错误与失败请求；
- 页面横向溢出；
- 加载遮罩是否退出、页面主体是否渲染。

关键场景另截图人工复核。共 29 个场景：

- 首页：1440 / 768 / 390 三种宽度、深色、带地球渲染；
- 列表视图：1440 / 390 两种宽度；
- 卡片密度：mini / compact / large；
- 缺字段数据（网格与列表）、超长名称（390）；
- 真实财务样本，汇率可用与离线两种；
- 未登录隐藏价格、站点关闭价格展示；
- 配置 500、节点列表 500；
- 详情页：1440 / 390、深色、隐藏尖峰样本、空历史、历史 500、节点 404、缺字段；
- 设置页：1440 / 390。

结果：除预期的 500 / 404 请求外，没有异常文字、控制台错误、失败请求或横向溢出；遮罩全部退出。错误场景都显示既有的错误提示与重试入口。

与上游一致、不作修改的表现：手机宽度下，总览卡每行 3 张，数值与单位都带 `truncate`，较长的「已用 / 总量」会被截断。这与上游 `NodeGeneralCards` 的 `grid-cols-3` 与 `unitClass` 相同。

## 源码与产物一致性

把本地构建与 CI 产物中的内容哈希统一替换后逐文件比对：

- 25 个文件中有 24 个完全一致；
- 入口文件只在 Vite 注入的预加载辅助函数里有 8 行差异：压缩变量名不同，以及 `new Error(...)` 与 `Error(...)` 这种等价写法；

因此这 8 行差异是 Windows 与 Linux 构建平台之间的工具链输出差异，不涉及本项目代码。

逐条核对设置页 46 项设置的说明文字与实际行为，修正五处对不上的描述。功能没有删减，数据逻辑未改动。

## 修复

- **「数据更新间隔」说明与取值范围**。原说明称服务端「约 5 秒一批」推送，并写明低于 5 秒会按 5 秒执行——于是这个输入框允许填 2，实际执行的却是 5。实测某站点每个节点约 2 秒收到一次推送，节奏跟随站点自己的上报配置，与 5 秒无关；那个 5 秒来自另一条上报路径的合并窗口，与本项无关。现在说明改为「只在 WebSocket 不可用时生效」，下限 5 秒的理由改为回退轮询自身的开销（每跳一次要重取站点配置与节点列表），取值范围与默认值一并收敛到 5–60 秒。**低于 5 的旧值在读取时归一到 5**，页面显示的就是真正会执行的间隔。
- **设置页新增一行当下状态**。这一项在 WebSocket 正常时一次也不会被读到，光看说明分不清此刻算哪种。现在会显示「最近一次观察：WebSocket 正常，此项未生效」或「WebSocket 不可用，此项正在生效」；没有观察到连接状态时不显示，不拿未知冒充正常。
- **「默认主题模式」的写回描述**。原说明称写入后端的取值只有 beijing / light / dark，且「跟随系统」对应 auto。实际四个取值原样写入 `theme_options.themeMode`，选「跟随系统」存的就是 `system`；auto 只在读取时作为历史值兼容。
- **「未登录隐藏价格」的生效范围**。原说明只提首页卡片与列表，实际详情页的节点价格、月均支出、剩余价值三张卡同样隐藏。另外首页总览卡片里本就没有财务项，原说明中的「费用类卡片」指向不明，已按实际范围逐项写明。
- **「毛玻璃配色方案」的作用范围**。原说明称只作用于节点卡，但激活态的快捷筛选胶囊同样使用该配色的表面色与文字色——与同组「自定义毛玻璃颜色 JSON」里写明的控制条颜色互相矛盾。现在两处口径一致。
- **「列表信息字段」里 asn 的原因**。原说明把 city 与 asn 归为同一个原因「依赖 IP 查询，服务端不提供」。asn 并非如此：它随节点标签下发，详情页的厂商格一直在显示；它在列表里被忽略是因为信息栏只实现了 provider / region / group / tags 四列。原因写错会把人引向探针配置去排查。
- **「隐藏头部」的描述**。原说明称会隐藏地球和总览卡片，实际只收走总览卡片，地球由「隐藏地球」单独控制。两项同时开启时头部区域才整体消失。行为保持不变，说明按实际改写。

## 更正

发布说明与文档中此前写着「温度字段服务端详情接口不返回，只有历史行里有」。复核服务端实现后确认：历史列集合与数据库结构里都没有温度列，公开接口中根本不存在这个字段，并非「在别处」。相关说明与文档已一并更正。

## 已知限制

以下各项在本版本中**仍然存在**，不宣称已解决：

- **详情页仍会取一次节点列表**：站点级的价格 / 到期 / 流量显示开关只出现在 `/api/servers` 的 `sysConfig`。该请求带守卫，只在直接打开或刷新详情页时发生一次。
- **首页每次 REST 刷新都会重取站点配置**：手动刷新、WebSocket 回退轮询与标签页重新可见都会同时请求 `/api/config` 与 `/api/servers`。两处守卫保证不会并发重复，但每跳一次仍是两个请求。
- **隐藏总览卡片但保留地球时，宽屏左侧会留白**：该布局把地球放在右半边，卡片本占左半边。实测无溢出、无遮挡、无错位，节点列表位置不变，窄屏也不受影响；本版本未调整。
- **延迟图的极高值**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值。
- **对话框输入框与描边按钮未接入配色方案**。
- **移动端触屏未实测**：气泡在真实触屏设备上的唤出方式没有实机证据。
- **真实环境未覆盖的边界场景**：超长节点名、无价格 / 免费、已过期、无探测目标与稀疏字段等只有本地构造样本的覆盖。
- **多 `apiBase` 缺少实机证据**：验收站点为单后端。

## 验证

- 代码检查、类型检查、单元测试（393 项）、构建与产物校验均已通过。新增用例把这几条说明逐条钉住：主题模式的说明不得再声称转存 auto，且时段断言直接驱动真实函数；价格说明必须覆盖详情页；配色说明不得再自称只作用于节点卡，并与自定义颜色说明交叉校验；列表字段必须分别说明两个键被忽略的原因；全部字段的说明文字扫一遍，出现指向其它主题的字样即失败。取值范围的用例断言低于下限的旧值会归一到 5。
- 服务端相关结论全部对着站点实际运行的版本复核：历史取样的两档点数上限与分桶取样、主题文件按 ref 代理与缓存、未登录时历史窗口上限 24 小时、以及时间范围九个档位与服务端允许值逐一对应。
- 设置页在本地实测：输入框下限为 5，说明与当下状态行按预期渲染。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.5
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.5.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退入口：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.4
```

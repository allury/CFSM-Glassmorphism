# CFSM Glassmorphism v1.1.0-test.1（测试版）

> **这是测试版，不是稳定版。** 用于验证首页向原 Komari Glassmorphism 的 1:1 复刻结果。
> 生产环境请继续使用 [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)。

本版本只改首页表现层，不触碰数据与协议层。

## 首页复刻改动

### 延迟 / 丢包柱状图（此前偏离最明显的地方）

上游用 `signal-1..5` 五级色阶给**满高**柱着色来表达数值；此前本主题自行发明了
「按数值缩放柱子高度的单色柱」，导致丢包为 0% 时面板几乎是空白。本版本改为：

- 柱子一律满高，数值由颜色分级表达——延迟 ≤60 / 100 / 160 / 200 ms，丢包 ≤1 / 3 / 6 / 9%；
- 完整移植上游 `--signal-1..5` 色阶，含亮色、暗色与两套色觉友好变体；
- 色觉友好模式叠加 `ping-signal-pattern` 纹理，使等级不只依赖颜色；
- 无采样时渲染 20 根中性占位柱，与上游一致，而不是留白。

### 卡片表面

上游所有卡片实际是 74% 不透明的浅色块加 1px 边框（一条 `!important` 规则覆盖了
Tailwind 的 `bg-background/50`）。此前本主题把它直译成半透明玻璃的 50%，叠加后只剩约 36%，
总览卡片在浅色背景上几乎没有边界。本版本移植上游的卡片表面令牌，总览卡与节点卡统一使用。

### 全局令牌

- 圆角 `--radius` 由 18px 改为上游的 10px；
- 字体栈改为系统字体优先，与上游 `--font-sans` 一致；
- 激活态改用上游的 `--selection` 强调色。

### 控制区

- 视图切换收敛为**卡片 / 列表**两个按钮；卡片密度回归主题设置，不再混进视图模式；
- 移除上游首页没有的排序下拉与结果计数；
- 搜索框改为折叠式：默认仅图标宽度，聚焦或有内容才展开，支持清空按钮与 ESC；
- 分组标签与快捷控制合并进同一个横向滚动容器；
- 快捷控制改用与上游同名的图标；
- 高级工具开关从 Header 移到控制区右侧，与上游 `homeTools` 位置一致。

### 布局

- 公告移到首页最前，位于总览与节点区之前；
- 节点网格单列起步，640px 以上才按密度 auto-fill；宽度 270 / 300 / 360 / 420，
  间距 12 / 12 / 16 / 20，与上游一致。

## 已知问题

见 [`docs/known-bugs.md`](../known-bugs.md)。两条均**不阻塞**首页视觉与交互对标：

- **BUG-001**：首页 Ping/Loss 窗口只能取自 `/api/servers` 的稀疏样本（约 20 点），
  上游可调用逐节点 ping 记录接口拿到更长历史。CFSM 没有等价公开端点，不做补点或插值。
- **BUG-002**：丢包面板显示聚合值，用户看不出「未配置 / 超时 / 真实 0」的区别。
  三态在数据层完整保留，详情页按目标逐项展示。

## 保持不变

REST、WebSocket 增量合并、多 apiBase 归属、History 与其并发保护、probe 三态、
`theme_options`、JWT / Turnstile、server ID 校验、重连退避、50+ 节点性能优化、
Earth 三渲染器、详情页结构、ECharts 图表与 UI 基元均未改动。

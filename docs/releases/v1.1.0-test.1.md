# CFSM Glassmorphism v1.1.0-test.1

## 更新了什么

- 延迟 / 丢包柱改为上游做法：柱子一律满高，数值由 `--signal-1..5` 五级色阶表达（延迟 ≤60 / 100 / 160 / 200 ms，丢包 ≤1 / 3 / 6 / 9%），含亮色、暗色与两套色觉友好变体；色觉友好模式叠加纹理，使等级不只依赖颜色。
- 全局令牌对齐上游：圆角 `--radius` 18px → 10px，字体栈改为系统字体优先，激活态改用上游 `--selection`。
- 控制区重排：视图切换收敛为卡片 / 列表两个按钮，卡片密度回归主题设置；移除上游没有的排序下拉与结果计数；搜索框改为折叠式（支持清空与 ESC）；高级工具开关移到控制区右侧。
- 布局：公告移到首页最前；节点网格单列起步，640px 以上按密度 auto-fill。

## 修复了什么

- 卡片表面不再是自创样式，改用上游 `[data-slot='card']` 实际生效的那条规则。
- 无采样时渲染 20 根中性占位柱，而不是留白。
- 已知未修：首页 Ping / Loss 窗口只能取 `/api/servers` 的稀疏样本（约 20 点）；丢包面板显示聚合值，看不出「未配置 / 超时 / 真实 0」的区别。

## 怎么安装

CFSM 后台「主题商店 → 自定义主题 URL」填入下面这条固定标签（测试版不会改变 `theme-dist` 指向的稳定版）：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.1
```

或下载本页的 `CFSM-Glassmorphism-v1.1.0-test.1.zip` 手动安装，解包后把根目录的 `index.html` 与 `assets/` 放到主题目录。

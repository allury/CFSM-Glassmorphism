# CFSM Glassmorphism v1.1.0-test.3

## 更新了什么

- 总览卡片内容改为上游的两段式：内存与硬盘显示「已用数值 + `GB / 总量 GB`」而不是百分比；系统分布显示占比最高的系统名 + `N 台`；预设内容与顺序逐项对齐上游 `GENERAL_CARD_PRESETS` 与 `ALL_GENERAL_CARD_KEYS`。
- 首页文本格式对齐上游：字节走 KB / MB / GB / TB / PB（基数仍为 1024），精度 B 0、KB 0、MB 1、GB 1、TB 2；运行芯片改为 `在线 N 天`；计费周期本地化为月 / 季 / 半年 / 年 / 两年 / 三年 / 四年 / 五年。这组格式只服务首页，详情页格式保持冻结。
- 快捷控制「完整」预设由八项收敛为六项（收藏、总流量、峰值、离线、高负载、即将到期），自定义模式仍可选上行 / 下行。
- 无自定义背景时改用上游的正式默认背景图（同一份资产，32436 字节），作为源码资源打包进 `assets/`，ZIP 根目录仍只有 `index.html` 与 `assets/`。

## 修复了什么

- 总览卡片表面完全改正：上游总览卡不走节点卡那条 `!important` 规则，此前照搬导致表面错误。
- 节点卡片改用上游默认玻璃预设的真实运行值：边框 `rgba(203,213,225,.6)`、圆角 14px。
- 球体版前六张卡片改为按列排布，与上游的显式栅格定位一致。
- tiled 渲染器的卡片跨度、行高、间距、内边距与地图高度按上游重排。
- 删除窄屏自创的间距与字号覆盖，总览卡片在所有断点都是 8px 间距 + 12px 内边距。
- 首页审计终态 P0 = 0、P1 = 0、FAIL = 0；21 个测试文件、183 个测试全部通过。

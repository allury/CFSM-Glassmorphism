# CFSM Glassmorphism v1.1.0-test.3（测试版）

> 本版本基于 v1.1.0-test.2，仅用于首页 UI/UX 尽量 1:1 高保真专项验证。允许存在已记录且不阻塞视觉对标的 KNOWN-BUG，不代表所有数据/逻辑问题均已修复。

> **这是测试版，不是稳定版。** 生产环境请继续使用
> [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)。

本版本把首页向原 Komari Glassmorphism 当前默认分支（`bf83765`）进一步对齐。
所有结论都来自两套 localhost 同时运行时的真实浏览器 `getComputedStyle` 与
`getBoundingClientRect` 对照，而不是源码断言。

## 修正

### 总览卡片

- **表面完全改正**。上游的总览卡片并不走节点卡片那条 `!important` 规则——CardX 用
  tailwind-merge 合并类名时，`bg-background/50` 与 `border-none` 把 `bg-card`、`border`
  直接删掉了。实测桌面态是 `--background` 的 50% + 无边框 + 10px 圆角 + 无阴影 +
  `backdrop-filter: none`，窄屏才有 `blur(8px)`，hover 变成不透明。
- **内容改为上游的两段式**：内存与硬盘显示「已用数值 + `GB / 总量 GB`」而不是百分比；
  流量与速率是「数值 + 单位」；计数类是「数值 + `/ 总数`、`台`、`个`」。
  「接收 + 发送」「在线节点合计」等说明文字移入 tooltip，手机端不再被挤成省略号。
- **系统分布**改为显示占比最高的系统名 + `N 台`，与上游一致。
- **球体版前六张卡片按列排布**（第 1、2 张上下叠在最左列），与上游的显式栅格定位一致。
- **预设内容与顺序**逐项对齐上游 `GENERAL_CARD_PRESETS` 与 `ALL_GENERAL_CARD_KEYS`。

### 首页文本格式

- 字节改用 KB / MB / GB / TB / PB（换算基数仍是 1024），精度 B 0、KB 0、MB 1、GB 1、TB 2，
  速度在单位后加 `/s`。
- 节点卡片的运行芯片改为 `在线 N 天`；节点列表的运行时间列仍是「天 + 小时」，
  与上游 NodeList 的精度一致。
- CFSM 官方计费周期本地化为 月 / 季 / 半年 / 年 / 两年 / 三年 / 四年 / 五年；
  未知的自由文本周期原样保留，不猜测它代表什么。
- 这组格式函数只服务首页卡片与列表，详情页格式保持冻结。

### 快捷控制

- 「完整」预设由八项收敛为六项：收藏、总流量、峰值、离线、高负载、即将到期，
  与上游去掉 CFSM 不支持的月费用估算后完全一致；基础 / 流量 / 运维同样重排。
- 允许的 key 集合改为独立常量，因此**自定义模式仍可选择上行 / 下行**。

### 默认背景

- 没有自定义背景时，改用上游的正式默认背景图（与上游同一份资产，32436 字节），
  连同 cover / center bottom / `saturate(1.12) contrast(1.02)` / `scale(1.01)`、
  暗色 `brightness(0.38) saturate(0.82) contrast(1.08)`、窄屏 `50% 78%` + `scale(1.02)` 一并移植。
- 资产作为源码资源打包进 `assets/`，主题 ZIP 根目录仍然只有 `index.html` 与 `assets/`。
- 后台配置的自定义图片 / 视频、模糊与遮罩能力不受影响。

### 卡片与栅格

- 节点卡片改用上游默认玻璃预设的真实运行值：边框 `rgba(203,213,225,.6)`、圆角 14px、
  hover 阴影与常态相同；暗色表面同步修正。
- tiled 渲染器的卡片跨度、行高、间距、内边距与地图高度按上游重排：
  窄屏两张一行、640px 起四张一行，地图高度改为下限值以便随容器拉伸。
- 删除窄屏自创的间距与字号覆盖，总览卡片在所有断点都是 8px 间距 + 12px 内边距。

## 验证

- 六档视口（375×812、430×932、768×1024、1024×768、1440×900、1920×1080）下，
  两版的总览区、地球、总览卡与节点卡的坐标、宽度与栅格列宽完全一致，
  仅节点卡高度相差 1.94px（记为 P2）。全部视口 `clientWidth === scrollWidth`，无横向溢出。
- 覆盖 light / dark、卡片 / 列表、0 / 1 / 10 / 30 / 64 节点、
  realistic / cobe / tiled、隐藏地球、隐藏工具、稀疏探测、401 / 503 错误态。
- 交互复核：分组、搜索（含 ESC 清空）、快捷筛选、收藏、视图切换、
  进入详情、返回后状态与滚动位置恢复。
- 首页审计终态：**P0 = 0、P1 = 0、FAIL = 0**，P2-ACCEPTED 4、KNOWN-BUG 2。
- 21 个测试文件、183 个测试全部通过；lint、typecheck、build、产物校验与 `git diff --check` 全绿。

## 未改动

REST、WebSocket 增量合并、10 秒稳定后重置退避、History、probe 的
`false` / `null` / 数值三态、`theme_options`、JWT、Turnstile、多 apiBase 归属、
50+ 节点性能优化、ECharts 与 UI 基元、v1.1.0-test.2 的详情页成果均保持不变。
本轮没有为解决纯显示问题去改数据适配层。

## 已知问题

见 [`docs/known-bugs.md`](https://github.com/allury/CFSM-Glassmorphism/blob/main/docs/known-bugs.md)：

两者都不阻塞首页视觉与交互对标，且不被标记为已通过。

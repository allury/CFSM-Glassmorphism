# CFSM Glassmorphism v1.1.0-test.4（测试版）

> 本版本仅用于 Detail / InstanceDetail UI/UX 尽量 1:1 高保真专项验证。允许存在已记录且不阻塞视觉对标的 KNOWN-BUG，不代表所有 CFSM 数据/逻辑问题均已修复。

> **这是测试版，不是稳定版。** 生产环境请继续使用
> [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)。

本版本基于 `v1.1.0-test.3`，把**详情页**向原 Komari Glassmorphism 当前默认分支
（`bf83765`）的 `InstanceDetail.vue` 收敛。所有结论都来自两套 localhost 同时运行时的
真实浏览器 `getComputedStyle` 与 `getBoundingClientRect` 对照，而不是源码断言。

首页在本轮只做回归验证，第 11 轮的成果全部保持不变。

## 修正

### 卡片表面

- **指标卡与信息卡的表面完全改正**。上游详情卡是 `--background` 的 50% + 无边框 +
  8px 圆角 + 无阴影 + 无 backdrop；本主题此前用的是自创的 `glass-panel`
  （`--glass` 的 50% + 6px 圆角 + 阴影 + `blur(8px)`）。
- 信息格改用上游对 `.bg-slate-500/5` 的覆盖值：亮色 `rgb(255 255 255 /.15)`、
  暗色 `rgb(255 255 255 /.05)`，6px 圆角、8px 内边距。
- 探针卡、GPU 卡、磁盘 IO 卡、历史图表卡、历史空/错误态一并统一到同一套表面，
  `glass-panel` 退出详情页。
- 顶部工具条与历史范围选择器改为上游的 `bg-background/50` 药丸组形态。

### 指标卡

- 改为上游的 **value + unit 两段式**：`USD18` + `/ 年`、`31` + `天`、`2.0` + `MB/s`、
  `50.0` + `%`。说明文字（内存明细、TCP/UDP、上下行总量等）降级为 tooltip，不再占一整行。
- **移除进度条**——上游详情指标卡没有进度条。
- 高度与字号按上游 `min-h-10 md:min-h-18`、`text-base sm:text-2xl` 对齐。
- 预设内容与顺序逐项对齐上游 `DETAIL_METRIC_CARD_PRESETS`；
  自定义模式的允许集合改为独立常量，`uptime` 与 `trafficQuota` 重新可选。
- 新增**剩余价值**卡（默认「财务」预设的第四张）。单节点不需要跨币种换算，
  因此按节点自身币种如实计算；免费节点显示「无」。
- 月均支出改为 `金额 / 月`，未知计费周期显示「不适用」而不是整卡消失。
- 剩余时间改用上游文案（`-` / 已过期 / 长期 / `N 天`）并按 5 / 10 / 36500 天阈值着色。

### 四张信息卡

- **硬件信息**补齐上游的 CPU 全宽块：图标 + `CPU` + PassMark「CPU Mark 排行」外链 +
  `型号 (N vCPU)` + 近似分级条。分级模块逐字移植自上游，只读取 CPU 型号字符串，
  不请求任何接口，也不产生 CFSM 之外的数据。
- **系统信息**补上 OS 图标与四个逐项图标。
- **存储信息**文案与图标按上游对齐（内存 / 内存交换 / 硬盘）。
- **网络信息**补齐配额进度背景（按使用率三档着色），用量文本改为解析后的
  「已用 / 配额」而不是原始 `traffic_limit` 字符串；速率改用 chevron 图标；
  上下行总量在 640px 以下隐藏，与上游一致。

### 分区 Tab

- `nodeDetailSectionTabsEnabled` 此前只是一个没有任何实现的空设置。
  本轮实现为上游的 **概览 / 负载 / 延迟** 三段（默认关闭，关闭时全部堆叠显示）：
  概览是指标卡 + 四张信息卡 + 磁盘 IO + GPU，负载是指标历史图，
  延迟是探针卡 + Ping / 丢包历史图。

### 显示格式

- 实测确认上游详情页与首页共用同一套字节与价格规则，因此第 11 轮的 `formatHome*`
  改名为 `formatDisplay*` 并在两页共用。**只是改名，首页输出完全不变。**
- 运行时间是两页唯一不同的地方，各自独立：首页节点卡到天、节点列表到小时、
  详情页到分钟且省略为零的单位（`3 天` 而不是 `3 天 0 小时`）。

## 验证

- 六档视口（375×812、430×932、768×1024、1024×768、1440×900、1920×1080）下，
  详情页的顶部导航、指标栅格、单卡尺寸与信息栅格列宽两版一致；
  仅指标卡在窄屏差 2px、硬件/系统卡在桌面差 2px（记为 P2）。
  全部视口 `clientWidth === scrollWidth`，无横向溢出。
- 覆盖 light / dark、分区 Tab 开关、`sparse=1` 探针缺失、
  `detailStatus=503`、非法 server id、`historyStatus=409`。
- 交互复核：上一台 / 下一台 / 节点选择器 / 收藏，全部保留 owning `source`。
- 首页回归：分组、快捷筛选、视图模式与滚动位置（555 → 详情 0 → 返回 555）全部恢复。
- 详情页审计终态：**P0 = 0、P1 = 0、FAIL = 0**，P2-ACCEPTED 2、
  NECESSARY-CFSM-DIFFERENCE 6、KNOWN-BUG 0。
- 22 个测试文件、207 个测试全部通过；lint、typecheck、build、产物校验与
  `git diff --check` 全绿。

## 必要的 CFSM 差异

以下上游内容因 CFSM 公开 API 不提供而隐藏，**不以估算值补位**：
真实 IP（`ip_v4` / `ip_v6` 只是可达性标志）、物理核心数、虚拟机类型、
厂商（精确城市 / ASN）、系统温度、近一天网速峰值。
逐条原因见 [`docs/detail-fidelity-audit.md`](https://github.com/allury/CFSM-Glassmorphism/blob/main/docs/detail-fidelity-audit.md)。

## 未改动

REST、WebSocket 增量合并、10 秒稳定后重置退避、History（九档时间范围 + revision +
AbortController）、probe 的 `false` / `null` / 数值三态、`theme_options`、JWT、
Turnstile、多 apiBase 归属、50+ 节点性能优化、ECharts 与 UI 基元，
以及第 11 轮的全部首页成果均保持不变。本轮没有为解决纯显示问题去改数据适配层。

## 已知问题

# CFSM Glassmorphism v1.1.0-test.4

## 更新了什么

- 详情指标卡改为上游的 value + unit 两段式（`USD18` + `/ 年`、`31` + `天`、`2.0` + `MB/s`），高度与字号按 `min-h-10 md:min-h-18`、`text-base sm:text-2xl` 对齐，预设内容与顺序逐项对齐上游 `DETAIL_METRIC_CARD_PRESETS`。
- 新增**剩余价值**卡（「财务」预设第四张）；月均支出改为 `金额 / 月`，未知计费周期显示「不适用」而不是整卡消失；剩余时间改用上游文案并按 5 / 10 / 36500 天阈值着色。
- 四张信息卡补齐上游内容：硬件信息加 CPU 全宽块与 PassMark「CPU Mark 排行」外链；系统信息补 OS 图标与四个逐项图标；存储信息文案与图标对齐；网络信息补配额进度背景（按使用率三档着色）。
- 实现 `nodeDetailSectionTabsEnabled` 分区 Tab——此前只是一个没有任何实现的空设置。
- 顶部工具条与历史范围选择器改为上游的 `bg-background/50` 药丸组形态。

## 修复了什么

- 指标卡与信息卡表面完全改正：上游详情卡是 `--background` 的 50% + 无边框，此前照搬了节点卡那套样式。探针卡、GPU 卡、磁盘 IO 卡、历史图表卡与历史空 / 错误态一并统一到同一套表面。
- 移除详情指标卡的进度条——上游没有。
- 实测确认上游详情页与首页共用同一套字节与价格规则，`formatHome*` 改名为 `formatDisplay*` 共用；运行时间是两页唯一不同的地方，各自独立。
- Windows 上 `bun run typecheck` 不会真正检查 SFC 模板，此前借此掩盖了一个真实的模板类型错误；已改用仓库外的便携 Node 复跑。

## 怎么安装

CFSM 后台「主题商店 → 自定义主题 URL」填入下面这条固定标签（测试版不会改变 `theme-dist` 指向的稳定版）：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.4
```

或下载本页的 `CFSM-Glassmorphism-v1.1.0-test.4.zip` 手动安装，解包后把根目录的 `index.html` 与 `assets/` 放到主题目录。

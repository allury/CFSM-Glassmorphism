撤下 v1.1.3 在延迟图上添加的取样提示，并把详情页的历史请求改为按发起顺序判定有效性。功能没有删减。

## 修复

- **延迟图的取样提示整块移除**。该提示在 v1.1.3 引入，用来说明长窗口下的数据由服务端分桶返回；复核服务端实现后确认它的表述并不准确（见下方「勘误」），继续挂在界面上只会误导。本版本删除它的文案、计算与样式，不以图标、气泡或占位替代，采样相关的说明只保留在文档与发布说明里。
- **同区域两行控件的版式回归**。提示的样式规则插在「曲线平滑」一行之前，把「全选 / 全不选」那一行从原有的组合选择器里带走了，于是它拿到了 `flex: 1`、顶端对齐、5px 间距与 11px 字号。该区域现已恢复到 v1.1.2 的取值：两行同为 `flex: 0 0 auto`、居中对齐、8px 间距、继承 16px 字号。
- **晚到的历史响应不再覆盖更新的一次**。此前只比较「窗口是否仍是当前窗口」，挡不住同一窗口的更早一次请求：按 1 小时 → 1 天 → 1 小时连续切换时，第一份 1 小时的响应最后到达，窗口比较依然成立，于是它会盖掉更晚发出的那份；同一窗口连续刷新时，一次晚到的失败还会把已经成功的数据清空并翻成错误态。现在每次请求单独编号，只认最后一次发起的那一个，成功与失败两条路径同样适用。

## 勘误

v1.1.3 的发布说明写过「窗口不超过 1 小时：不套用点数上限，返回该区间内的全部上报记录」。这句话不准确，此处更正，该版本的标签与发布包不做改动。

服务端对两类窗口都分桶取样，只是上限不同：窗口大于 1 小时时用站点配置的 `long_history_points`，否则用服务端常量 160；桶宽为 `max(10 秒, 窗口跨度 / 上限)`，每个桶只返回一条记录。1 小时窗口的桶宽约 23 秒，通常宽于节点自己的上报间隔，因此结果看起来接近全量——那是数据密度低于桶宽的结果，不是接口的保证。

## 关于取样精度

- **窗口不超过 1 小时**：上限为 160 点，桶宽约 23 秒。
- **窗口超过 1 小时**：上限为站点配置的 `long_history_points`，桶宽按窗口跨度等比放大。部分部署会对丢包列取桶内最大值，是否走这条路径取决于该部署的历史表索引优化状态。

把窗口调回 1 小时，恢复的是该窗口在更细桶宽下的采样，不构成「还原全部尖峰」的承诺。

本主题不做任何再加工：不削峰、不插值、不把缺失值改成 0，`connectNulls` 保持关闭，探测返回 `false` / `null` 与缺列一律按缺失渲染。服务端的取样配置不在主题的职责范围内，本版本未改动。

## 已知限制

以下各项在本版本中**仍然存在**，不宣称已解决：

- **详情页仍会取一次节点列表**：站点级的价格 / 到期 / 流量显示开关只出现在 `/api/servers` 的 `sysConfig`，`/api/server?id=` 的同名字段里没有；上一台 / 下一台与节点选择器也需要这份列表。该请求带守卫，只在直接打开或刷新详情页时发生一次，从首页点进详情页不会触发。
- **首页每次 REST 刷新都会重取站点配置**：手动刷新、WebSocket 回退轮询与标签页重新可见都会同时请求 `/api/config` 与 `/api/servers`。两处守卫保证不会并发重复，但每跳一次仍是两个请求。是否合并留待后续版本评估。
- **延迟图的极高值**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值，因此个别尖峰仍会压缩常态区间的可读性。
- **对话框输入框与描边按钮未接入配色方案**：这两类元素使用自己的表面色，不随配色方案变化。
- **移动端触屏未实测**：统计卡在窄屏下会截断，完整值由提示气泡承担。气泡在真实触屏设备上的唤出方式没有实机证据，模拟器派发的仍是鼠标事件。
- **真实环境未覆盖的边界场景**：验收站点的节点未出现超长节点名、超长系统名、无价格 / 免费、已过期、无探测目标、离线节点与稀疏字段等情形，这些场景只有本地构造样本的覆盖。
- **多 `apiBase` 缺少实机证据**：验收站点为单后端，多来源部署下必须保留 `?source=` 与按来源取配置的分支只有单元测试与本地覆盖，没有真实环境验证。

## 验证

- 代码检查、类型检查、单元测试（378 项）、构建与产物校验均已通过。新增的用例把历史响应按测试指定的顺序放行，逐条覆盖联动切换、独立窗口与同窗口连续刷新下的五种乱序；回退这次的时序判断后，其中三条立刻失败。另有两条用例以可追踪的连接桩驱动真实状态，断言连开三台节点期间任何时刻最多只有一条未关闭的实时连接，离开详情页后一条不剩。
- 真实部署验收：线上 22 个资源全部可达且与构建产物逐字节相同，`index.html` 的差异仅为 CFSM 注入的站点标题与图标。详情页冷启动 4 个请求；从首页进入 2 个；负载图切换时间范围 1 个且两图联动；延迟图选到相同窗口 0 个、选到不同窗口 1 个。提示已不存在，两行控件的取值在 1440 浅色、1440 深色与 375 深色下一致，无横向溢出，全程无控制台报错。检查过程为只读，视口与配色方案只用浏览器本地模拟并已复位，未修改站点的主题配置。

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.4
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.4.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退入口：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.3
```

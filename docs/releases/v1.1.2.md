# CFSM Glassmorphism v1.1.2

顶部区域的专项修复版本：修好首页顶部统计卡的文字偏移，让滚动后的站点顶栏回到应有的表面处理，并整理了界面文案。其余功能与 v1.1.1 相同。

## 修复

- **顶部统计卡的单位偏移**：单位与「已用 / 总量」说明相对主数值上浮并贴死主数值。原因是数值行的布局类被当作透传属性交给提示组件，而提示组件的根节点只渲染插槽，该属性落不到任何元素上——浏览器实测这个类在页面里命中 0 个元素，数值行退回提示组件自身的 `inline-flex`，失去基线对齐与间距。现在数值行是提示组件内部一个独立的容器，有提示与无提示两条分支使用相同的结构与类名。1440 实测：修复前单位基线比主数值高 9px、间距 0；修复后基线差 0、间距 4px。
- **滚动后的站点顶栏**：此前会刷上一层不透明度约 77% 的背景、`blur(20px) saturate(155%)` 与一层投影。现在改为透明背景 + `blur(16px)` + 一条低透明度边框，不带阴影。顶栏高度、内容宽度、Logo 与按钮位置均未改变；首页、详情页、设置页共用同一顶栏。
- **统计卡图标配色**：常态与悬浮改用固定的中性蓝灰，不再随主题的次要文字色变化。

## 变更

- 设置页开头改为说明设置项数量与保存行为。
- 配色方案那条说明改为描述其实际作用范围（节点卡的表面色、边框、阴影与文字色）；此前的说法在 v1.1.1 之后已不准确。
- 界面里解释某项设置为何失效的说明，改为直接说明缺少哪个 CFSM 字段、写入后会被忽略。字段名、原因与提示内容都保留。

## 一处旧结论的更正

v1.1.1 的已知限制里曾把「顶栏与顶部统计卡尚未接入配色预设」列为遗留项。本版本在浏览器里逐条实测后确认该前提不成立：这两处按设计就不由配色预设驱动，顶部统计卡的表面处理（常态、悬浮、深色与窄屏下的模糊）也本就是正确取值。配色预设仅驱动节点卡这一组变量，该项不再列为限制。

## 已知限制

以下各项在本版本中**仍然存在**，不宣称已解决：

- **延迟图的极高值**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值，因此个别尖峰仍会压缩常态区间的可读性。
- **控制类元素未接入配色预设**：选中态的控制胶囊、对话框输入框与描边按钮使用本主题自己的表面色，不随配色预设变化。它们不在顶部区域，本版本未改动。
- **移动端触屏未实测**：统计卡在窄屏下会截断，完整值由提示气泡承担。气泡在真实触屏设备上的唤出方式没有实机证据，模拟器派发的仍是鼠标事件。该行为自 v1.1.1 起未改动。
- **真实环境未覆盖的边界场景**：验收站点的节点未出现超长节点名、超长系统名、无价格 / 免费、已过期、无探测目标、离线节点与稀疏字段等情形，这些场景只有本地构造样本的覆盖。
- **多 `apiBase` 缺少实机证据**：验收站点为单后端，多来源部署下必须保留 `?source=` 的分支只有单元测试与本地覆盖，没有真实环境验证。

## 验证

- 代码检查、类型检查、单元测试（364 项）、构建与产物校验均已通过。新增的数值行回归用例以服务端渲染断言真实 DOM 结构，而不是断言源码里出现过某条样式；单独回退属性透传的修复后，该文件 8 项中有 4 项立即失败。
- 本地对照在同一台机器、同一浏览器、同一视口与同一组展示数据下进行，覆盖 375 / 767 / 768 / 1440 / 1920 五个宽度、明暗两套主题、四种内置配色方案与自定义配色、地球关闭 / 球体 / 平铺三种顶部布局。
- 真实部署（Worker `2.8.5 Beta5`，5 台真实节点）验收：线上入口资源与候选产物逐字节相同，22 个资源全部可达；五张统计卡在 1440 浅色、1440 深色与 375 下均为基线差 0、间距 4px；顶栏三态在首页、详情页、设置页取值一致；悬浮与移出的表面切换、提示气泡的完整值均正常。检查过程为只读，未修改站点的主题配置。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.2
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.2.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退入口：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.1
```

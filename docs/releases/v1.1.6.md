# CFSM Glassmorphism v1.1.6

<!-- store-label: 顶栏显示站点图标 -->

顶栏左上角改为显示站点自己的图标。其余功能与 v1.1.5 相同。

## 修复

- **顶栏站点标记改用站点图标**。这个位置此前是一枚固定的装饰图形（翡翠圆环套蓝点），纯 CSS 绘制：它既不是站点自己的标识，也不随配色方案变化——配色方案只驱动节点卡与控制条的七个变量，这枚标记用的两个色值都不在其中，因此切换任何方案它都保持原样。现在优先显示站点图标，与页面标签上的图标一致。

  取值有三级回退，任何一级都不会让这个位置空着：

  1. **站点图标**。CFSM 把后台「网站图标」作为 `<link rel="icon">` 注入页面，值通常是 data URI；站点配置接口不返回这个字段，因此从页面上已有的那一条读取。未设置时该注入不存在，退到 `/favicon.ico`，CFSM 自带一张默认图标会在此响应。
  2. **站点名首字**。图标缺失或加载失败时启用。
  3. **原有的几何标记**。站点名也为空时才出现。

  容器本身的尺寸、圆形、毛玻璃底与描边都未改动，图标铺满并按比例裁剪进这个圆。

## 已知限制

以下各项在本版本中**仍然存在**，不宣称已解决：

- **详情页仍会取一次节点列表**：站点级的价格 / 到期 / 流量显示开关只出现在节点列表接口的 `sysConfig`。该请求带守卫，只在直接打开或刷新详情页时发生一次。
- **首页每次 REST 刷新都会重取站点配置**：手动刷新、WebSocket 回退轮询与标签页重新可见都会同时请求站点配置与节点列表。两处守卫保证不会并发重复，但每跳一次仍是两个请求。
- **隐藏总览卡片但保留地球时，宽屏左侧会留白**：该布局把地球放在右半边，卡片本占左半边。实测无溢出、无遮挡、无错位，窄屏不受影响。
- **延迟图的极高值**：「曲线平滑」只改变折线曲率，不重写、不过滤、不插值任何采样值。
- **对话框输入框与描边按钮未接入配色方案**。
- **移动端触屏未实测**：气泡在真实触屏设备上的唤出方式没有实机证据。
- **真实环境未覆盖的边界场景**：超长节点名、无价格 / 免费、已过期、无探测目标与稀疏字段等只有本地构造样本的覆盖。
- **多 `apiBase` 缺少实机证据**：验收站点为单后端。

## 验证

- 代码检查、类型检查、单元测试（399 项）、构建与产物校验均已通过。新增用例覆盖三级回退的每一级、服务端渲染下的取值守卫、以及图标加载失败时的降级；其中一条专门锁住「几何标记不得再挂在容器的 `::before` 与后代 `span` 上」——留在原处的话，站点图标显示时它们会画在图标底下。
- 真实部署验收：线上 23 个资源全部可达且与候选产物逐字节相同，入口引用与候选包内一致。顶栏实测渲染为站点图标，原生尺寸 256×256、按 30×30 呈现并裁剪进圆形容器，容器伪元素的 `content` 为 `none`（确认旧标记已不参与绘制）；深色与 375 窄屏下同样正常，无横向溢出。
- 回归项未受影响：详情页冷启动仍为 4 个请求，延迟图无取样提示，两行控件取值不变，两类图默认同为 1 小时；首页、设置页、详情页在深色与窄屏下全程无控制台报错。
- 检查过程为只读，视口与配色方案只用浏览器本地模拟并已复位，未修改站点的主题配置。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」中填入不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.6
```

也可以下载本页的 `CFSM-Glassmorphism-v1.1.6.zip` 手动安装：解包后，将根目录的 `index.html` 与 `assets/` 部署到主题目录。

回退入口：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.5
```

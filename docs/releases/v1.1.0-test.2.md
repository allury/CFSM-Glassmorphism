# CFSM Glassmorphism v1.1.0-test.2

## 更新了什么

- 补齐上游 `tabler:calendar-stats` 与 `tabler:coins` 图标，仍为构建期内联，运行时不访问外部 CDN。

## 修复了什么

- Earth 隐藏时总览卡片恢复上游的 3 / 6 列独立网格，不再出现卡片宽度异常或右侧大片留白。
- 手机节点卡片底部保持三列，速率、流量、到期与金额各自有独立的窄屏省略层。
- 第三列不再直接输出完整 ISO 日期，改为与上游一致的「剩余 N 天」/「已过期」/「长期」/「—」。
- 375 / 430 / 768 / 1024 / 1440 / 1920 六档视口均无页面级横向溢出。

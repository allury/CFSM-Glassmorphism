# CFSM Glassmorphism v1.1.0-test.2（测试版）

> **这是测试版，不是稳定版。** 用于验证首页隐藏 Earth 与手机节点卡片的补充修复。
> 生产环境请继续使用 [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)。

本版本只修正 `v1.1.0-test.1` 实机截图暴露的两个首页问题。

## 修复

- Earth 隐藏时，总览卡片恢复 Komari 的 3 / 6 列独立网格，不再因隐式列出现卡片宽度异常或右侧大片留白。
- 手机节点卡片底部保持三列，速率、流量、到期与金额文本都拥有独立的窄屏省略层。
- 第三列不再直接输出完整 ISO 日期，而是与 Komari 一致显示「剩余 N 天」、「已过期」、「长期」或「—」。
- 补齐上游 `tabler:calendar-stats` 与 `tabler:coins` 图标；图标仍为构建期内联，运行时不访问外部 CDN。

## 验证

- 双版本 localhost 以计算样式和 DOM 几何复核隐藏 Earth 的网格规则。
- 375 / 430 / 768 / 1024 / 1440 / 1920 六档视口均无页面级横向溢出，底部信息框稳定为三列，总览卡片等宽。
- 数据与协议底座、Ping 柱、Earth renderer、节点点击路径与详情页结构均未改动。

## 安装

测试版只发布不可变的固定标签，不会改变 `theme-dist` 滚动分支指向的稳定版：

~~~text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.2
~~~

或从本 Release 下载 `CFSM-Glassmorphism-v1.1.0-test.2.zip` 手动安装。

# CFSM Glassmorphism v1.1.0-test.5

## 更新了什么

- 先完整审读 CF-Server-Monitor Worker `2.8.5 Beta5` 与探针 Agent `1.3.8` 的采集、上报、存储、REST、WebSocket 与 History 全链路，建立字段级数据契约，再按契约审计实现。所有结论都能回指到具体源码位置或真实部署的响应样本。
- 新增 `docs/cfsm-source-audit.md`（数据链总图、端点契约、含单位与空值语义的字段契约表）与 `docs/bug-matrix.md`（逐项分类矩阵）。

## 修复了什么

- **首页延迟 / 丢包柱时间轴错位**。`/api/servers` 的 `ping` / `loss` 是时间桶序列（固定 20 点、覆盖 2 小时、每点含全部 8 个探测目标），此前被拍平成一维数组并过滤掉空洞，浏览器实测渲染出 68 根柱而不是 20 根，一个空洞就会让后续柱子整体前移。现在一桶一柱，`null` 保留为原位空洞。
- **首页整段丢掉 `node_1`～`node_4`**。类型与遍历只覆盖旧四线路，导致 CFSM 2.8.5 起新增的 4 个探测点在首页从不显示；只配置了 node 探测点的节点首页探针区完全空白。现在首页与详情页统一走 8 个目标。
- **站点级 `show_price` / `show_expire` / `show_tf` 完全失效**。这三个开关只在 `/api/servers` 响应**顶层** `sysConfig` 出现，而代码读的是每台节点上的字段（列表里恒为 `undefined`），运营方的隐藏设置形同虚设。现在集合级开关会下发到每台节点。
- **总览卡片单位抢占主数值宽度**。`.overview-card__unit` 此前写了 `flex: none` + `max-width: 60%`，硬占六成宽度，768px 实测 `455.0` 被截成 `45…`；上游那个单位只有 `truncate`。
- 复核后关闭一条旧 KNOWN-BUG，并修正另一条的结论：20 点 / 2 小时确实是服务端写死的常量（改记为上游限制），但「视觉结构已对齐」是错的——真正的错位就藏在里面。

## 怎么安装

CFSM 后台「主题商店 → 自定义主题 URL」填入下面这条固定标签（测试版不会改变 `theme-dist` 指向的稳定版）：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0-test.5
```

或下载本页的 `CFSM-Glassmorphism-v1.1.0-test.5.zip` 手动安装，解包后把根目录的 `index.html` 与 `assets/` 放到主题目录。

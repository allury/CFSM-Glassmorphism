# CFSM Glassmorphism v1.1.0

第二个正式版本，取代 [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)，汇总 `v1.1.0-test.1` 至 `v1.1.0-test.5` 的全部成果。

## 变更

- 图表序列配色改用逐字移植自基准 `chartPalette.ts` 的具体色值调色板；坐标轴、图例与 tooltip 的文字及底色改用基准 `chartThemeColors` 的同一组 rgba，随浅色与深色实时重算。
- 色觉友好模式整体切换至基准的无障碍调色板（`#0072B2`、`#E69F00`、`#CC79A7` 等），线型改用基准的 `solid` / `dashed` / `dotted`。
- 详情页通过直达链接进入时，补发一次首页既有的 `/api/servers` 请求（仅一次，不轮询），并补齐冷启动时为空的「上一台 / 节点选择器 / 下一台」。
- 内存、硬盘与交换内存卡片的 tooltip 补全为完整的「已用 / 总量」及占比；系统分布与地区分布改用基准 `formatDistributionTooltip` 的完整列表。

## 修复

- **详情页历史图表折线渲染为黑色**。图表使用 ECharts 的 `CanvasRenderer`，序列颜色最终写入 canvas 2D 的 `strokeStyle`，而 canvas 不解析 CSS 变量，`var(--emerald)` 类取值被丢弃，折线沿用上一次的绘制样式。同一组取值同时用于 HTML tooltip 色点与底部摘要色点，HTML 侧可正常解析，因而两者表现不一致。画布像素实测：9 张图表的绘图区由仅含 `0,0,0` 变为调色板色值，并与底部色点逐一相等。
- **浅色模式下图表内图例文字对比度不足**。根因同上。修复后浅色为 `rgba(0,0,0,0.55)`，深色为 `rgba(255,255,255,0.55)`，与基准一致。
- **首页指标数值与延迟面板数值字重高于基准**。实现写为 600，基准为 500；该字族仅有 Regular 与 Bold 两档实体字面，500 匹配 Regular、600 匹配 Bold，导致整列数字加粗。
- **详情页徽章尺寸与字重偏离基准**。由 11px / 600 改为基准的 12px / 500 / line-height 16px，高度随之与基准 `h-5` 的 20px 一致。
- **字体栈与渲染选项包含基准中不存在的声明**。移除自行追加的 `"Microsoft YaHei"`，以及项目模板引入的 `font-synthesis: none` 与 `text-rendering: optimizeLegibility`；站点名与分区标题恢复为 600 并移除自定义负字距；图表 tooltip 字号由 11 调整为 12。
- **详情页直达链接时站点级展示开关失效**。运营方关闭的价格、到期与流量配额仍会显示。现于开关取得前先行隐藏，避免已关闭的价格短暂可见。
- **总览卡片长数值截断后无法读取完整值**。截断行为与基准一致，但基准的三张卡片未提供 tooltip，完整值在两侧均不可读；现通过既有 tooltip 补全，未改动任何几何。

## 已知问题

- 行高：实现多处使用 `line-height: normal`，基准为 Tailwind 的具体值。该偏差被更大的内边距抵消，单独对齐会使卡片几何进一步偏离基准，留待后续专项处理。
- 图表形态：基准 `LoadChart` 内联的 CPU、内存、磁盘、网络与 GPU 图表带渐变填充且线宽为 1.5，本实现统一为纯折线、线宽 1.6。
- 延迟与丢包面板的主数值取自最新一条上报，基准取窗口平均值。已复核数据来源正确，`null`、`false` 与缺失均未转换为 0，非数据错误，但「卡片显示 0% 而历史图存在丢包」的视觉差异仍然存在。
- 反馈的「悬浮网络图表时曲线消失」未能复现：两档视口、三个悬浮位置下曲线像素数均无变化。

## 安装

在 CFSM 后台「主题商店 → 自定义主题 URL」填入滚动分支，随最新稳定版更新：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-dist
```

固定在本版本请使用不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0
```

亦可下载本页的 `CFSM-Glassmorphism-v1.1.0.zip` 手动安装，解包后将根目录的 `index.html` 与 `assets/` 部署到主题目录。

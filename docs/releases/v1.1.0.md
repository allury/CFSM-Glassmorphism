# CFSM Glassmorphism v1.1.0

第二个正式版，取代 [v1.0.0](https://github.com/allury/CFSM-Glassmorphism/releases/tag/v1.0.0)，汇总 `v1.1.0-test.1` ～ `test.5` 的成果。

## 更新了什么

- 图表配色改为逐字移植上游 `chartPalette.ts` 的具体色值调色板；坐标轴 / 图例 / tooltip 的文字与底色改用上游 `chartThemeColors` 的同一组 rgba，随浅色 / 深色实时重算，切换主题不再残留旧颜色。
- 色觉友好模式改为整体切换到上游的无障碍调色板（`#0072B2` / `#E69F00` / `#CC79A7`…），线型也改用上游的 `solid` / `dashed` / `dotted`，不再只改线型。
- 详情页直达链接时会补发一次首页本来就在用的同一个 `/api/servers`（只发一次、不轮询），顺带补齐冷启动时空着的「上一台 / 节点选择器 / 下一台」。
- 内存 / 硬盘 / 交换内存卡的 tooltip 补全为「完整已用 / 总量 + 占比」；系统分布与地区分布改用上游 `formatDistributionTooltip` 的完整列表。

## 修复了什么

- **详情页历史折线全是黑的**。根因不是配色表写错，是颜色根本没进画布：图表走 ECharts 的 `CanvasRenderer`，序列颜色最终落到 canvas 2D 的 `strokeStyle`，而 **canvas 不解析 CSS 变量**——`var(--emerald)` 被直接丢弃，线条留在上一次的绘制样式上。同一批值又用于 HTML tooltip 色点与底部摘要色点，HTML 能解析，于是「线黑、点对」。画布像素实测：9 张图的绘图区从「只有 `0,0,0`」变成调色板色，与底部色点逐一相等。
- **浅色模式下图内图例文字偏白**，同一根因。修复前是不透明白色，现在浅色 `rgba(0,0,0,0.55)`、深色 `rgba(255,255,255,0.55)`，与上游一致。
- **首页指标数值与延迟面板数值比上游粗一档**。字重写成 600，上游是 500——该字族只有 Regular 与 Bold 两档实体字面，500 落 Regular、600 落 Bold，整列数字都被加粗了。
- **详情页徽章比上游更小更粗**：11px / 600 改为上游的 12px / 500 / line-height 16px，高度随之与上游 `h-5` 相等的 20px。
- **字体栈与渲染选项混入了上游没有的东西**：删除自行追加的 `"Microsoft YaHei"`，以及 Vite 模板带来的 `font-synthesis: none` 与 `text-rendering: optimizeLegibility`。站点名与分区标题改回 600 并去掉自造负字距，图表 tooltip 字号 11 → 12。
- **详情页直达链接时站点级开关完全失效**：运营方关掉的价格、到期与流量配额照常显示。现在开关拿到之前先隐藏，避免把已关闭的价格闪出来。
- **总览卡长数值被截断后读不出来**：截断本身与上游同等，但上游那三张卡根本没有 tooltip，完整值两边都无从读取；现在用已有 tooltip 补全，未改任何几何。
- 未修复并已记录：行高仍用 `line-height: normal`（单独对齐反而会让卡片几何离上游更远）；上游 `LoadChart` 内联图带渐变填充而本主题是纯折线；延迟 / 丢包面板主数值显示的是最新一条上报而非上游的窗口平均（已复核来源正确、空值未变成 0）；反馈的「悬浮网络图时曲线消失」在两档视口三个悬浮位置均未能复现。

## 怎么安装

CFSM 后台「主题商店 → 自定义主题 URL」填入滚动分支，以后跟随最新稳定版：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-dist
```

想固定在这一版就填不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.1.0
```

或下载本页的 `CFSM-Glassmorphism-v1.1.0.zip` 手动安装，解包后把根目录的 `index.html` 与 `assets/` 放到主题目录。

# CFSM Glassmorphism v1.0.0

这是面向 CF-Server-Monitor 公共第三方主题 API 的首个稳定版 Komari Glassmorphism 移植。

## 版本亮点

- 首页仪表盘、卡片/列表导航、详情层级、响应式断点、动效和图标均以 Komari 为视觉与交互基准，并保留三套真实 Earth 渲染器（`globe.gl` + `three`、`cobe`、tiled map）。
- 完整接入 CFSM REST、多 apiBase 归属、WebSocket partial update 与重连、单节点详情订阅，以及基于 ECharts 的稀疏 History 图表。
- 旧 CT/CU/CM/BD 与 Node 1～4 Ping/Loss 全部支持，并在全链路保持 `false` / `null` / 数值三态。
- 主题设置采用 defaults、后端 `theme_options`、本地覆盖三层模型；带 JWT 与 Turnstile 的后端保存只使用 `POST /api/theme_options`。
- 已实际验证空数据、部分来源失败、全部离线、401、403、409、5xx、稠密节点、主题、renderer、减少动画和六档浏览器视口。

## CFSM 必要差异

- 公共 CFSM 主题 API 不提供真实 IP、ASN、城市或精确坐标，因此 Earth 只做国家/地区级定位。
- 管理功能继续由 CFSM 的 `/admin#admin` 提供；访客信息和审计日志因没有公开主题 API 而保持隐藏。
- Footer 归因指向 CF-Server-Monitor。第 8 轮高级工具能力继续保留，但默认收起，使正式版首页层级与 Komari 保持一致。

## 安装方式

从本 Release 下载 `CFSM-Glassmorphism-1.0.0.zip`，通过 CFSM 官方主题安装流程安装。压缩包根目录只包含 `index.html` 与 `assets/`。

## 质量验证

GitHub Actions 只有在 frozen dependency install、lint、严格 typecheck、全部单元/契约测试、生产 build 和 dist 结构/体积校验全部成功后，才会生成并发布本版本压缩包。

# CFSM Glassmorphism v1.0.0

## 更新了什么

- 首页仪表盘、卡片 / 列表导航、详情层级、响应式断点、动效与图标以 Komari Glassmorphism 为视觉基准，保留三套真实 Earth 渲染器（`globe.gl` + `three`、`cobe`、tiled map）。
- 完整接入 CFSM REST、多 apiBase 归属、WebSocket partial update 与重连、单节点详情订阅，History 图表基于 ECharts。
- 支持旧 CT/CU/CM/BD 与 Node 1～4 的 Ping / Loss，全链路保持 `false` / `null` / 数值三态。
- 主题设置为 defaults、后端 `theme_options`、本地覆盖三层模型；后端保存只用 `POST /api/theme_options`，带 JWT 与 Turnstile。
- 公共主题 API 不提供真实 IP、ASN、城市与精确坐标，因此 Earth 只做国家 / 地区级定位；管理功能仍在 CFSM 的 `/admin#admin`。

## 修复了什么

首个正式版，无历史版本可修。已实际验证空数据、部分来源失败、全部离线、401 / 403 / 409 / 5xx、稠密节点、主题、renderer、减少动画与六档浏览器视口。

## 怎么安装

CFSM 后台「主题商店 → 自定义主题 URL」填入滚动分支，以后跟随最新稳定版：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-dist
```

想固定在这一版就填不可变标签：

```text
https://github.com/allury/CFSM-Glassmorphism/tree/theme-v1.0.0
```

或下载本页的 `CFSM-Glassmorphism-v1.0.0.zip` 手动安装，解包后把根目录的 `index.html` 与 `assets/` 放到主题目录。
